# That Open Master challenges

This is a live repository that progresses through the curriculum of **That Open Master** programme.

Upon downloading this repository, cd to `that-open-master` folder and folow either of these two options:

## Option 1. If you have Node and NPM installed
Run `npm install`.
Then run `npm run dev`.

## Option 2. If you have Docker and Docker Compose installed
Run `./setup.sh`.
If you need to access the Docker container for running any additional npm commands, run `./shell.sh`.

In both cases, the page should be available at: http://localhost:5500/
